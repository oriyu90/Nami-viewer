# NamiVision 0.1.0

音声ファイルの**全体波形**と、**周波数帯域ごとの波形（最大4本）**をDAWのように表示し、
BPM・拍子・小節開始位置から作った拍グリッドに対して、各帯域の音の立ち上がりが
「拍の頭からどれだけずれているか」を計算して **CSV** に出力する Windows 用デスクトップアプリです。
簡易音楽プレイヤーとしても使えます。

- コアは Rust、UI は WebView2 上の HTML/CSS/Canvas
- インストール不要のポータブル版（単一 exe）
- 日本語 / English、ダーク / ホワイト、UI 倍率 80–150%

---

## 1. 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 11 / Windows 10 22H2 以降（64bit） |
| ランタイム | Microsoft Edge WebView2 ランタイム（Windows 11 は標準搭載。Windows 10 も Edge の更新で通常導入済み） |
| 空き容量 | 約 30 MB |
| インストール | 不要（zip を展開して exe を実行） |

WebView2 が無い場合は起動時に案内が表示されます。
[Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) から「Evergreen Bootstrapper」を導入してください。

## 2. 起動と基本操作

1. zip を任意のフォルダに展開します（Program Files など書込不可の場所でも起動できます）。
2. `NamiVision.exe` をダブルクリックします。
3. 音声ファイル（**mp3 / wav / flac / ogg**、**5秒以上**）をウィンドウへドラッグ＆ドロップするか、
   右上の「開く」から選択します。
4. `Space` で再生 / 一時停止、`S` で停止（先頭へ）です。

初回起動時は何も読み込まれていないため、中央のドロップゾーンが表示されます。

### 画面の見かた

├──────────────────────────────────────────────────────────────┤
│ 0:00      0:05      0:10      0:15        ← 時間ルーラー      │
│ MASTER ▁▂▅█▇▅▂▁  （全体波形 + 小節/拍グリッド）              │

│ LOW-MID ▁▂▁▅▃▁   （250–1,000 Hz）                            │

- 最上段 **MASTER** が曲全体の波形です。
- 2段目以降が周波数帯域ごとの波形です（既定4本、設定で1–4本・境界変更可）。
- 上部の再生バーをクリック / ドラッグするとシークできます。

## 3. テンポ（BPM・拍子・小節開始）の設定

**MASTER レーンを右クリック → 「テンポ設定…」** を選びます。

- **BPM**: 20–400。数値入力のほか、`Tap` を4回以上叩いて平均から求めることもできます。
- **拍子**: 2 / 3 / 4 / 6 / 8 拍子。
- **小節開始**: 曲頭からの秒数。`再生ヘッド位置を使用` で現在位置を代入できます。
- **グリッド表示**: 小節線・拍線・分割線を表示します。
- **スナップ**: 小節開始フラグをドラッグしたとき拍に吸着します。

設定すると、ルーラーに小節番号と拍目盛りが表示され、**琥珀色の「1」フラグ**が小節開始位置に立ちます。
このフラグはレーン内で左右にドラッグして微調整できます（1ms単位）。

MASTER レーンの右クリックメニューから「ここを小節開始に」を選ぶと、クリックした位置を小節開始にできます。

## 4. 拍のずれを CSV に出力する

1. 先に **テンポ設定** を済ませます（BPM・拍子・小節開始）。
2. 出力したい**帯域レーン**（2段目以降）を右クリックします。
3. **「拍のずれを CSV 出力」** を選びます。
   - テンポ未設定のとき、この項目はグレー表示で押せません。
4. 保存先を選ぶと CSV が書き出されます。

### 計算方法

拍番号 `k`（小節開始を 0 とする整数）の拍時刻は

```
T_k = barStart + k × (60 / BPM)
```

その帯域のオンセット強度（音の立ち上がり）を `±0.45 拍` の範囲で探索し、
最大点を放物線補間して精密な立ち上がり時刻 `t_onset` を求めます。

```
ずれ(ms)   = (t_onset − T_k) × 1000
ずれ(拍)   = (t_onset − T_k) ÷ (60 / BPM)
```

- **正の値 = 拍より遅い（後ろ）**
- **負の値 = 拍より早い（前）**
- 立ち上がりが見つからない拍は `undetected` になります（設定で行の省略可）。

### CSV の列

| 列 | 意味 |
|---|---|
| `band_index` | 帯域名の番号（1始まり） |
| `band_label` | `Low` / `Low-Mid` / `Mid-High` / `High` |
| `frequency_range_hz` | 例 `20-250` |
| `beat_index` | 小節開始を0とした拍番号（負もあり） |
| `bar` | 小節番号（小節開始が1） |
| `beat_in_bar` | 小節内の拍（1始まり） |
| `expected_time_s` | 理論上の拍時刻（秒） |
| `onset_time_s` | 検出した立ち上がり時刻（秒） |
| `deviation_ms` | ずれ（ミリ秒、正=遅れ） |
| `deviation_beats` | ずれ（拍単位） |
| `onset_strength` | 立ち上がり強度 0–1 |
| `status` | `detected` / `undetected` |

CSV は Excel でそのまま開けるよう **UTF-8 BOM 付き・CRLF** で出力します。
区切り文字と小数桁は設定で変更できます。

## 5. プロジェクト（JSON）の保存と読込

ヘッダの **「プロジェクト」** から保存 / 読込できます。

保存される内容:

- 音声ファイルのパス・名前・長さ
- BPM・拍子・小節開始・分割・グリッド/スナップ
- ズーム・スクロール位置・選択レーン・再生ヘッド追従
- 帯域の境界と色
- 再生位置・音量
- 言語・テーマ・UI倍率

音声そのものは埋め込まれません。別の PC で開いた場合などに音声が見つからないときは、
設定（テンポなど）を復元したうえで「音声を再選択」バナーが表示されます。
再選択してもテンポ設定は失われません。

## 6. 設定

ヘッダの **「設定」** から変更できます。変更は即時反映され、自動保存されます。

| セクション | 設定 |
|---|---|
| 一般 | 言語（日本語 / English）、テーマ（ダーク / ホワイト）、UI倍率（80–150%） |
| 再生 | 音量、波形ゲイン、再生ヘッド追従 |
| 解析 | FFTサイズ（1024 / 2048 / 4096）、帯域数（1–4）、帯域境界（3点）、オンセット感度 |
| 出力 | CSV区切り（`,` / `;`）、小数桁（0–6）、未検出行を含める |
| 情報 | バージョン、データ保存先、ポータブル状態 |

設定の保存先:

- 通常: `%APPDATA%\com.namivision.app\settings.json`
- ポータブル: exe と同じフォルダに `portable.txt` を置くか、`--portable` 引数で起動すると
  `exeのフォルダ\data\settings.json` に保存されます。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 起動時に WebView2 の案内が出る | [WebView2 ランタイム](https://developer.microsoft.com/microsoft-edge/webview2/) を導入 |
| 「5秒以上の音声を選んでください」 | 5秒未満のファイルは解析できません |
| 音が出ない | Windows の出力デバイスを確認。解析・CSV出力は音が出なくても利用できます |
| CSV 出力が押せない | 先に MASTER レーンの右クリックからテンポ設定を完了してください |
| 音声が見つからない | プロジェクト読込後に「音声を再選択」から同じ音声を指定 |
| 設定を初期化したい | 設定 → 情報 に表示される保存先の `settings.json` を削除 |

## 9. ソースからビルドする場合

Rust 1.77 以降と MSVC Build Tools が必要です。Node.js は不要です。

```powershell
cargo build --release
# target\release\nami-vision.exe
```

セルフテスト（GUI なし）:

```powershell
cargo run --release -- --selftest --selftest-dir .\selftest
```

テスト:

```powershell
cargo test
node --test tests/frontend
```
